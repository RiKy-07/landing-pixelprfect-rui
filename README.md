# landing-pixelprfect-rui

Positivus Landing Page (Pixel Perfect Recreation)

This project was given to me from my supervisor Eladio Tchiinhemba from Bisc8. I had the mission to recreate visually and pixel-perfect a figma project of a landing page (Positivus)

How I made it?

Technologies used: HTML, Styles: CSS and SCSS, JavaScript.

I basically recreated the structure of the project, his sections and some other blocks, and for that, I used a lot of divs in HTML, and then worked with CSS properties to deal with the display of everything. I had the JavaScript main file to add some functionalities, that I failed to add (23/10/2025), such as Menu, Accordions and Sliders.

Lessons that I learned:

A website requires so much more than I used to believe, I'd consider this my first really big project, with so many directories and files, and I really improved so much on my programming practices, specially on styling.
